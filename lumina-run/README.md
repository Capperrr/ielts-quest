# LUMINA · 霓光跃迁

一个原创的、可在浏览器直接游玩的 **3D 霓虹都市飞行小游戏**。本游戏使用 Three.js 实时 WebGL 渲染，存放在独立的 `lumina-run/` 目录，不修改原有 IELTS Quest、贴纸或反馈网页。

## 试玩链接

当仓库 GitHub Pages 采用 main 分支根目录发布后，游戏地址为：

**https://capperrr.github.io/ielts-quest/lumina-run/**

## 玩法与操作

玩家是为未来城市送达最后一束光的悬浮飞行器驾驶员。任务持续约75秒：

- 收集至少 **12 枚金色光粒子**，坚持到最后即可达成黎明结局。
- 避开紫粉色障碍无人机；护盾降为零则任务失败。
- 光脉冲能清除前方近距离的障碍，但有 **7秒冷却**。
- 连续收集光粒子可获得连击加分。
- 最佳分数会保存在当前浏览器本地，不会跨设备同步。

**电脑：** 方向键 ← / → 或 A / D 切换航道，空格释放光脉冲，Esc 暂停/继续。

**手机 / iPad：** 屏幕下方左右按钮切换航道，右侧 ✳ 释放光脉冲。也支持在游戏画布上左右滑动变道。手机竖屏可以玩，横屏能获得更宽的视野。

## 技术及美术

- **Three.js 0.160.1** ES module，由 esm.sh 加载。需要首次联网。
- 程序化原创3D美术：建筑、窗光、悬浮飞行器、空中轨道、霓虹广告牌、粒子、全息环、灯光与发光轨迹。
- HTML/CSS：电影式标题、玻璃质感 HUD、触控、暂停和结算界面。
- Web Audio API：由用户交互触发的简易合成音效，无外部版权音乐。
- 不需要账户、服务器、AI API、登录或收费服务。
- 使用本地存储保存最高分。

## 验收标准

- WebGL成功启动，菜单界面渲染真实3D都市。
- 按钮 / 键盘切换航道，飞行器有平滑的倾斜动画。
- 收集光粒子增加数量、连击和得分。
- 障碍触碰消耗护盾，短暂无敌防止连击伤害。
- 光脉冲清除附近危险物，并显示冷却状态。
- 75秒后依据收集量呈现胜利或失败。
- 可暂停、重开、返回菜单；最高分保留在本机。
- 手机、iPad、电脑能加载界面；需要实机验证不同GPU和浏览器兼容性。

## 已知限制

这是完整核心循环的独立小游戏，而不是成熟商业3D游戏。都市美术为**程序化原创3D模型与光效**，尚不包含美术师手绘/生成的高精贴图、专业配音及正式配乐。GitHub Actions 可验证脚本语法与页面引用，但不能代替iPad、iPhone及不同GPU浏览器的真实游玩测试。

当前用于表现速度的城市会沿轨道循环，偏重街机视觉效果而非写实城市地图。
