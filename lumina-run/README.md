# LUMINA 2.0 · 霓光跃迁

原创 Three.js WebGL 3D 霓虹飞行游戏，单人、无需登录、支持电脑、手机、iPad 浏览器。

**游戏地址（本分支合并并由 GitHub Pages 发布后）**：https://capperrr.github.io/ielts-quest/lumina-run/

保存在独立的 `lumina-run` 目录，**不会修改 IELTS Quest 及其他旧项目**。

## 三关故事模式

| 关卡 | 场景 | 完成条件 | 关卡亮点 |
|---|---|---|---|
| 01 · 霓光高架 | Aurora Causeway | 47秒内至少收集8枚光粒子并存活到终点 | 霓虹城市地标、教学节奏 |
| 02 · 天轨城区 | Sky Rail District | 55秒内至少收集12枚光粒子并存活到终点 | 悬浮列车、移动无人机与更密集的光轨 |
| 03 · 核心塔区 | Nexus Core | 66秒内至少收集16枚光粒子并存活到终点 | 巨型核心塔、哨兵遭遇、终章演出 |

每完成一关，解锁下一关。通关可获得星级与 S / A / B / C 评级。第一、二关分别解锁 ROSE 和 SOLAR 飞行器色彩。关卡成绩、星级、解锁状态和尾迹配色保存在本机浏览器。

光脉冲可清除前方接近的障碍，包括第三关的核心哨兵，但有冷却时间。额外奖励包括连击、擦肩而过的加分等。最佳分数仅本机可见。

## 操作

电脑：← / → 或 A / D 变道；空格释放光脉冲；Esc 暂停/恢复。

手机 / iPad：**左下角左键、右下角右键、右键上方光脉冲**。也支持游戏画布左右滑动变道。

手机竖屏有独立的镜头和 HUD 布局；宽屏拥有更广阔的视野。

## 美术与音乐

采用原创程序化 3D 建筑、全息招牌、赛博空中轨道、能源塔、发光粒子与立体飞行器。每个关卡的场景色彩、地标和难度都有差异。

原创 Web Audio 合成音效包括环境和弦、引擎低频、节奏鼓点、光粒子双音反馈、受击声和光脉冲扫频。音频仅在玩家主动开始游戏后启用，可静音。

无外部商业游戏素材、无需游戏后端。当前 Three.js 使用固定版本的公开 ESM CDN，因此首次打开需要网络。

## 测试

```bash
node lumina-run/verify.cjs
```

自动化浏览器测试（需要安装 Playwright Chromium）：

```bash
node lumina-run/smoke.cjs
```

GitHub Actions 会执行静态检查及桌面 / 竖屏浏览器自动化测试，覆盖三关连续通关、下一关解锁、本地存档、手机控制按钮位置与功能。

> 注意：Chromium 模拟测试不能替代真实 iPhone Safari、iPad Safari 和 Android 手机的全面性能测试。游戏不等同于成熟商业3A作品；后续仍可增加专业贴图、人物动画、后期泛光和更丰富的事件。

## 主要文件

- `index.html`：响应式 UI、三关选择与结果界面
- `style.css`：电影化美术与手机控制布局
- `game.js`：核心玩法、3D城市与交互
- `lumina2.js`：三关场景增强、进度存储与原创音频引擎
- `smoke.cjs`：浏览器游戏过程与触控布局测试
- `verify.cjs`：静态代码与资源引用检查
