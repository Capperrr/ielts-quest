# IELTS Quest · 失落的词语之城（Pixel RPG）

这是独立于仓库根目录旧版 IELTS 训练网页的像素探索游戏。**不会替换**原有 `index.html`、`sticker-world` 或 `teacher-feedback`。

## 试玩

若 GitHub Pages 使用 `main` 分支根目录发布，访问：

https://capperrr.github.io/ielts-quest/quest-rpg/

需要联网加载 Phaser 3.90.0 引擎（cdnjs CDN）。没有账号、没有后端，学习进度存储在本机浏览器的 localStorage 中。

## 操作

- 电脑：WASD 或方向键移动，E / 空格靠近装置互动；Esc 打开设置。
- 手机/iPad：屏幕左侧方向键，右侧「互动」键，支持触控；横屏和竖屏均可打开。
- 进入发光装置完成雅思写作练习；每个章节答对四道**此前未正确完成**的题目，解锁下一章节。完成第五章后在章节门触发结局。
- 顶部「地图」可切换已解锁章节，「手账」可查看错题与学习进度。
- 同一浏览器刷新会保存进度；不同设备不会同步。

## 内容

五大区域：遗忘的图书馆、逻辑之桥、数据观测站、观点议会、修辞高塔。

练习机制：词语填空、配对、论证句子排序、实际柱状图判断、Overview 判断、Task 2 审题多选、段落修复、综合写作。

内置原创练习数据，启动时浏览器控制台会输出数据校验概览。

## 局限与下一步

当前是**可试玩的第一版原型**：关卡共享基础地图结构和程序化像素素材，尚未制作独立的精细角色贴图、多章节专属地图、完整NPC剧情、音乐音效及高级奖励系统。游戏分数不等于雅思官方成绩。教学内容仍建议真人教师复核。手机和iPad实机兼容性尚需人工测试。

不需要 npm 构建即可发布；Phaser 从稳定 CDN 加载。测试题库：

```bash
node quest-rpg/verify.cjs
```
