# 午夜汤局 · Midnight Soup Club

An independent browser game with **120 original Chinese lateral-thinking puzzles**, including horror, disturbing, suspense, absurd and comedy cases.

## How to play

1. Open the GitHub Pages HTTPS game page at `/ielts-quest/turtle-soup/`.
2. Select a case, then choose 玩家 (player) or 主持人 (host).
3. Players see only the story and two clues. The first clue unlocks after **four minutes**. The second becomes available **four minutes after the first clue is opened**.
4. Hosts need a privately shared master key to decrypt the answer. The key is not stored or displayed in the website source.
5. Share the player-only link generated by the game rather than a host screen.

- All 120 answers were re-encrypted after editing, and the previous host key no longer decrypts the current vault.

## Technical privacy and limitations

- `puzzles.json` contains only player-visible story text and hints.
- `vault.json` contains encrypted solutions using PBKDF2-SHA256 and AES-256-GCM; no plaintext answers are committed.
- Because this is a **static website**, a short or widely shared host password is **not robust authentication against determined users**. Encryption discourages casual accidental spoilers; stronger secrecy would require a high-entropy password or a server-backed authentication system. Do not share the host key with players.
- Local clue timers are a convenience rule, not an anti-cheat authority. A user who edits browser state or inspects the public hint JSON can bypass waiting times; plaintext answers still require the host key.
- Favorites, solved marks, and hint timers live in browser storage.

## Deployment

Publish the repository's `main` branch using GitHub Pages, root folder. Open `https://capperrr.github.io/ielts-quest/turtle-soup/`. If GitHub Pages is not enabled or the deployment is delayed, this link may show a 404 until it is configured.
