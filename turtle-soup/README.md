# 午夜汤局 · 330 道海龟汤 v7

## 本轮更新

- **内容审查**：保留 330 道题，其中 29 道重写汤面、两条提示和汤底；89 道重新分类。将仅属于一般设备故障、寻物、事故的题目从“重恐/惊悚”降至悬疑、生活推理、科学谜题；将真正存在持续隐蔽威胁的重恐题保留为独立筛选。详见 `editorial-audit.md`。
- **细思极恐**：对经复核的一批题目标注“细思极恐”。恐怖依靠合理的线索、隐藏的真实危险和后知后觉，而不是单纯的伤亡或惊吓。
- **单人推理**：选择“单人推理”进入，写推理笔记并自动保存在本机；开局 1 分钟 / 4 分钟解锁线索；完成后输入一次主持密钥核对汤底，再自行标记是否猜中。不是 AI 问答或自动评分，避免编造“是/否”答复。
- **多人游戏**：选择多人后再选择玩家或主持人；主持人密钥 `winter` 解密汤底；玩家端不加载明文汤底。
- **密钥与单人模式的限制**：本项目是静态站点。若让单人用户无需密钥就获得汤底，必然允许多人玩家换模式偷看。故保留单人核对密钥；知道密钥的人无法被静态网站彻底阻止作弊。真正在互不信任的玩家间隔离答案需增加后端服务和身份鉴权。
- **计时**：第一条 1 分钟、第二条 4 分钟（需先看第一条）。分别保存单人与多人模式的本地计时，关闭浏览器或修改设备时间会影响计时。
- **节目素材**：T321–T330 来自用户上传的《名侦探学院》节目截图，保留来源和截图能支持的原意，新增提示为原创编辑。

## 文件

`index.html`（网页） + `puzzles.json`（公开汤面与线索） + `vault.json`（AES-256-GCM 加密汤底）。如需一份单独上传到静态托管的页面，用 `standalone.html`。静态资源无需第三方字体服务。

## 质量声明

程序已运行题库数量、编号、JSON 字段、密钥解密、两提示不同、HTML 语法检查与移动端互动回归测试。并非 330 道题已全部由真人逐题完整推演，后续仍可继续发现并修复逻辑问题。
