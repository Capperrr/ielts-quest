# 午夜汤局 · 320 道独立原创海龟汤（v5）

## 玩法

- **原有 120 题保留，新增 200 题，总共 320 题**。
- 新增类别包括重恐、惊悚、重口、悬疑、生活推理、科学谜题、校园、黑色幽默、荒诞与搞笑。
- 第一条提示：进入题目后 **1 分钟** 解锁。
- 第二条提示：进入题目后 **4 分钟** 解锁，需先看过第一条提示；不从第一条点击时间重新计时。
- 线索遵循由观察角度到证据细节的推进方式，完整汤底以事件顺序、机制、可验证线索构成。
- 玩家只看汤面与提示；主持人使用 **winter** 解密完整汤底。注意：密码容易被猜测，无法替代真正的服务端身份认证。
- 主文件：index.html；公开题库：puzzles.json；加密汤底：vault.json。三个文件放同一目录即可经 HTTPS 静态托管运行。
- 备用单文件：standalone.html，含公开题面与加密答案，无需额外 JSON 下载；在可正常执行 JavaScript 和 WebCrypto 的 HTTPS 网站使用最佳。
- 没有引入海外字体及外部 JS 依赖。

## 编辑和技术校验

- 200 道新增题目经过逐条写作并检查 7 项字段；确认 ID、标题不重复；每道都包括汤面、答案、两个独立提示和类别。
- 编写时优先使用日常可解释的现实机制、证据推断和明确规则；部分荒诞与黑色幽默题属于预先说明的趣味设定。
- 自动验证题库条目、答案匹配、AES-GCM 解密以及错误密码拒绝；这些检查不等于已经完成 320 道的真人主持试玩。
